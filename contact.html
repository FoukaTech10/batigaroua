Le projet

BâtiGaroua est un site pédagogique réalisé dans le cadre du cours de Création de site web, parcours Ingénierie de la Construction. Il vulgarise les principes de la construction durable adaptée au climat du Nord-Cameroun.

Technologies utilisées

  • HTML5 : structure des six pages
  • CSS3 : mise en forme et responsive design
  • JavaScript : menu mobile, checklist, validation du formulaire
  • Hébergement statique gratuit (GitHub Pages)
Limites : projet pédagogique, sans base de données. Le formulaire est une démonstration : aucun message n'est réellement transmis.
